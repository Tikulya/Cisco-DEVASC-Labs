Лабораторная работа №9 — Parse Different Data Types with Python

Цель работы

Изучить методы обработки структурированных данных XML, JSON и YAML с использованием языка программирования Python. Научиться извлекать значения из файлов и преобразовывать данные между форматами.


Использованные инструменты

Cisco DEVASC VM
Python 3.8.2
Библиотека xml.etree.ElementTree
Библиотека json
Библиотека PyYAML
Терминал Linux
